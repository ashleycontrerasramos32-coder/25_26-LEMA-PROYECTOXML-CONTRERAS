#YAPEROSHOP - XML proiektua

Proiektu honek barne hartzen ditu:

-** XML**: catalogo.xml (produktuen egitura)
-** DTD**: katalogoa.dtd (oinarrizko baliozkotzea)
-** XSD**: catalogo.xsd (baliozkotze aurreratua motekin, murrizketekin eta patternekin)
-** XSL**:
- catalogo_total.xsl → produktu guztiak erakusten ditu
- catalogo_kategoriaka.xsl → kategoriaka erakusten ditu produktuak
